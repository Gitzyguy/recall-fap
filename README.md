# RECALL: FortiAP 7.6 (installable app)

Files: index.html, manifest.webmanifest, sw.js, and four icons. Upload all of them together to one folder on any HTTPS host (GitHub Pages works).

Install
- iPhone or iPad: open the site in Safari, tap Share, then Add to Home Screen.
- Android: open it in Chrome, then tap Install app (or menu > Add to Home screen).
- Desktop Chrome or Edge: click the install icon in the address bar.

After the first visit it works offline. Progress stays on the device; use Weak areas > Backup to export and import it.

To ship an update, upload the new index.html and change CACHE in sw.js (for example recall-fap76-v2).
